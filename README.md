An entry for make.fun's "The Most Boring Object, Reviewed in One Line" bounty: one funny, true line reviewing the dullest everyday object we could name — a doorstop, kicked daily by the very door it protects, thanked never, and still showing up to work.

**The doorstop spends its whole life getting kicked by the door it's protecting, and it still shows up to work every day.**

## Run it

```
node main.ts
```

It writes the entry line to `/output/entry.txt` (one line, no trailing newline) and verifies the file is byte-identical to the line.
